# Audio sources

The game uses a small, curated subset of CC0 sound packs instead of importing the
full archives. The original license file from each pack is stored beside its
audio files.

| Pack | Source | Included files | Use |
|------|--------|----------------|-----|
| Kenney Impact Sounds | [Godot Asset Library #1841](https://godotengine.org/asset-library/asset/1841), [Kenney source](https://www.kenney.nl/assets/impact-sounds) | `impactMetal_light_001.ogg`, `impactMining_002.ogg`, `impactPunch_heavy_001.ogg`, `impactPunch_medium_000.ogg`, `impactWood_heavy_001.ogg`, `footstep_grass_000.ogg` through `002.ogg` | Bomb placement, hits, stomp, breakage, footsteps |
| Kenney Digital Audio | [Godot Asset Library #1833](https://godotengine.org/asset-library/asset/1833), [Kenney source](https://kenney.nl/assets/digital-audio) | `lowDown.ogg`, `powerUp4.ogg` | Down state and pickups |
| Kenney Sci-Fi Sounds | [Godot Asset Library #1834](https://godotengine.org/asset-library/asset/1834), [Kenney source](https://kenney.nl/assets/sci-fi-sounds) | `explosionCrunch_002.ogg`, `forceField_000.ogg`, `lowFrequency_explosion_000.ogg` | Explosions, shields, bosses, thunder |
| Kenney Interface Sounds | [Godot Asset Library #794](https://godotengine.org/asset-library/asset/794) | `confirmation_001.wav`, `select_001.wav` | Confirmation and inventory selection |

All four packs are released under Creative Commons CC0. Attribution is not
required, but the source list is retained for provenance and future updates.
